深度学习是一种机器学习技术，它使用多层神经网络来处理数据并学习表示。与传统的机器学习方法不同，深度学习模型能够自动从大量数据中提取复杂的特征，从而减少对人工设计特征的依赖。这种能力使得深度学习在图像识别、语音识别、自然语言处理等领域取得了显著的成果。

本文主要介绍我的深度学习环境搭建，基础学习方法等。

## 环境搭建

使用下面的PyTorch官方CUDA二进制包，或在受支持的Linux/WSL2环境安装tensorflow[and-cuda]时，所需CUDA运行库和cuDNN会随包或依赖安装，通常只需预先安装兼容的NVIDIA驱动，不必单独安装系统级CUDA Toolkit。编译框架或自定义CUDA扩展时，仍可能需要本地Toolkit；CPU包和其他安装方式不能一概而论。

### Python环境搭建

我的Python环境主要依赖于uv，有关uv的详细内容可以参考我的博客[uv 项目管理](/%E5%B7%A5%E5%85%B7/uv/)

### PyTorch环境搭建

有关PyTorch的详细内容可以参考[PyTorch官方文档](https://pytorch.org/)

#### PyTorch-Python版本对应关系

安装最新版本的PyTorch，可以直接去[PyTorch官方文档](https://pytorch.org/)查看所需Python版本和安装命令。

需要安装旧版的PyTorch，就要查看[PyTorch-Python版本对照表](https://github.com/pytorch/pytorch/blob/main/RELEASE.md#release-compatibility-matrix)和[PyTorch安装命令](https://pytorch.org/get-started/previous-versions/)。

#### pip安装PyTorch镜像

下载较慢时可以尝试阿里云镜像，速度和可用版本以实际网络和镜像同步情况为准。

注意：--find-links（-f）只是增加候选下载链接，不等于替换--index-url（-i）。下面的示例同时指定CUDA本地版本后缀，避免仅凭-f地址误以为一定安装了对应CUDA构建；也可以直接使用官方安装命令。

```bash
pip install torch==2.5.1+cu124 torchvision==0.20.1+cu124 torchaudio==2.5.1+cu124 -f https://mirrors.aliyun.com/pytorch-wheels/cu124
```

上海交通大学镜像使用包索引结构，这里用--index-url：

```bash
pip install torch==2.5.1+cu118 torchvision==0.20.1+cu118 torchaudio==2.5.1+cu118 --index-url https://mirror.sjtu.edu.cn/pytorch-wheels/cu118
```

#### 安装命令

初始化项目

```bash
uv init
```

配置pyproject.toml。下面每个代码块是独立方案，选择一份使用，不要把重复的TOML表直接拼在一起；需要多种后端时使用“自选安装”的完整方案。

这些是历史版本范围示例，不是最新兼容性清单。先按所选版本设置[project]中的requires-python和项目Python版本，并核对系统、架构与显卡驱动支持。python_version条件不满足时，对应依赖会被跳过，不会自动切换Python。

##### cpu

```toml pyproject.toml
[project.optional-dependencies]
cpu = [
  "torch>=1.12.0",
  "torchvision>=0.13.0",
  "torchaudio>=0.12.0",
]

[tool.uv.sources]
torch = [
  { index = "pytorch-cpu" },
]
torchvision = [
  { index = "pytorch-cpu" },
]
torchaudio = [
  { index = "pytorch-cpu" },
]

[[tool.uv.index]]
name = "pytorch-cpu"
url = "https://download.pytorch.org/whl/cpu"
explicit = true
```

```bash
uv sync --extra cpu
uv run --extra cpu python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available())"
```

uv add jupyter pandas matplotlib

### Tensorflow环境搭建

安装最新版本的Tensorflow，可以直接去[Tensorflow官方文档](https://www.tensorflow.org/install)查看所需Python版本和安装命令。

#### Tensorflow版本对应关系

在Linux环境下安装Tensorflow GPU版的[版本对应关系](https://tensorflow.google.cn/install/source#gpu)

在Windows环境下安装Tensorflow GPU版的[版本对应关系](https://tensorflow.google.cn/install/source_windows#gpu)

> **info**
> 原生Windows的CUDA GPU支持止于TensorFlow 2.10；2.11及以后的GPU版本可按官方说明使用WSL2。

#### Linux环境下安装Tensorflow

安装最新版Tensorflow的CPU版本

```bash
uv add tensorflow
```

安装最新版Tensorflow的GPU版本

```bash
uv add "tensorflow[and-cuda]"
```

### 非root用户安装本地CUDA

如果你没有root权限，无法安装系统级的CUDA Toolkit，可以选择安装到自己的目录；系统仍需由管理员安装兼容的NVIDIA驱动。这里我选择安装多个版本的CUDA Toolkit，通过使用统一的cuda软链接来选择不同的CUDA版本。

#### 下载CUDA Toolkit

前往[CUDA Toolkit下载页面](https://developer.nvidia.com/cuda-toolkit-archive)下载适用于Linux的CUDA Toolkit，这里安装类型选择runfile下载。

![1.png](/images/knowledge/%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0/%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0/1.png)

#### 安装CUDA Toolkit

截图演示runfile的选择方式；下面命令以CUDA 12.4.0的Linux x86_64安装包为例，文件名和目录应与实际下载的版本一致。

```bash
chmod +x cuda_12.4.0_550.54.14_linux.run
```

```bash
./cuda_12.4.0_550.54.14_linux.run --silent --toolkit --toolkitpath="$HOME/.local/cuda-12.4"
```

#### 创建cuda软链接

```bash
ln -s $HOME/.local/cuda-12.4 $HOME/.local/cuda
```

覆盖已经存在的软链接。

```bash
ln -sfn $HOME/.local/cuda-12.4 $HOME/.local/cuda
```

#### 配置环境变量

将以下内容添加到你的`~/.bashrc`文件中：

```bash
export CUDA_HOME=$HOME/.local/cuda
export PATH=$CUDA_HOME/bin:$PATH
export LD_LIBRARY_PATH="$CUDA_HOME/lib64${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
```

#### 验证安装

安装完成后，运行`nvcc --version`命令验证CUDA Toolkit是否安装成功。
